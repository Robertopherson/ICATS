# ICATS Manual

ICATS generates molecular-scattering initial conditions and analysis diagnostics
for quasi-classical trajectory workflows. This manual is a working guide to the
whole pipeline: install the code, generate initial conditions, run the provided
tutorials, inspect Wang-Landau sampling, run cheap MINDO dynamics, and interpret
the analysis output.

## Current Status

The code repository is the main source for ICATS. The manual lives in the
`docs/` directory so it can be read directly on GitHub. Later, the same files
can be published as a GitHub Pages site.

The manual is intentionally practical: each section should explain what the
user needs to run, what files are created, what the main outputs mean, and what
checks should be made before trusting a calculation.
