# Project Background

ICATS was developed as an educational and research tool for postgraduate
students learning the theoretical ingredients behind quasi-classical
bimolecular scattering: rigid rotors, normal modes, Eckart-frame analysis,
Jacobi coordinates, angular-momentum coupling, and Wang-Landau sampling. The
same ideas are used to prepare initial conditions for quasi-classical
trajectory calculations and to analyse the Cartesian coordinates and velocities
that those calculations produce.

The project grew out of work supported by the EPSRC New Directions in Molecular
Scattering programme grant EP/T021675/1, a collaboration involving Heriot-Watt
and Oxford researchers. Outreach material based on cheap semi-empirical toy
simulations was also produced to illustrate molecular-collision ideas in a more
visual form.

The core scientific model and original implementation were developed through
conventional research programming and are described in the accompanying
manuscript. AI-assisted coding tools were later used, under author supervision,
to improve the command-line interface, tutorials, diagnostics, documentation,
and outreach material. The author remains responsible for the scientific
content, implementation choices, and limitations described in this manual.
